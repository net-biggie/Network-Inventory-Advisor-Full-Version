<a id="key-features"></a>

### Core Functionality:
- **Comprehensive Device Inventory** — Quickly access a database of all devices connected to your network, with the ability to add offline computers.
- **Unified Summary View** — View all connected hardware, device types, and operating systems in a single window.
- **Software License Control** — Maintain oversight of software on each device, including license key management.
